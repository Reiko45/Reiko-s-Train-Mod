# GitHub release notes for 1.0.0

Tag `v1.0.0` on `main`, title "Reiko's Train Mod 1.0.0", and attach `reikotrains-1.0.0.jar`. Paste everything below the line.

---

The first full release of Reiko's Train Mod, for Minecraft 1.21.1 (NeoForge 21.1.265+).

Big steam, diesel and electric trains on their own track, the Bullet Train, trams in the street, signals from two to four aspects, a signal box with routes, timetables, freight loading, depots and turntables, and a track-laying wagon that builds the line for you. See the [README](https://github.com/Reiko45/Reiko-s-Train-Mod#readme) for everything.

**Needs [BuildCraft Reborn](https://github.com/Reiko45/BuildCraft-Reborn) 2.1.0 or newer.** Optional: Reiko's Car Mod 1.39+, Xaero's Minimap and World Map, Patchouli (the Railway Handbook), JEI.

Install it on the server and on every player's game, the same version on each. From 1.0.0 on, updates keep worlds working.

Changes since 0.29.0: the in-game description covers the whole mod, and Xaero's World Map is listed as an optional dependency. Full history: [CHANGELOG.md](https://github.com/Reiko45/Reiko-s-Train-Mod/blob/main/CHANGELOG.md).
