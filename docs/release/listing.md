# Mod page details (Modrinth and CurseForge)

What to fill in when making the project pages. The page text itself is `description.md` in this folder (Markdown;
both sites take it as it is). The icon is `icon-512.png` (the mod's logo, enlarged).

## Project

| Field | Value |
| --- | --- |
| Name | Reiko's Train Mod |
| URL slug | `reikos-train-mod` |
| Summary (Modrinth, up to 256 characters) | Big steam, diesel and electric trains on their own track, trams in the street, signals, a signal box, timetables, freight, and a wagon that lays the line for you. With an in-game handbook. |
| Categories | Transportation (main), Technology |
| Environment | Client: required. Server: required |
| Loader | NeoForge |
| Minecraft version | 1.21.1 |
| License | GPL-3.0 (on Modrinth, choose GPL-3.0-only, or GPL-3.0-or-later if you want to allow later versions of the GPL) |
| Source | https://github.com/Reiko45/Reiko-s-Train-Mod |
| Issues | https://github.com/Reiko45/Reiko-s-Train-Mod/issues |
